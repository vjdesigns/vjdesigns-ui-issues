# vjdesigns-ui issues

Public issue tracker for **vjdesigns-ui**, the accessible, themeable component library for React, Angular and Vue.

The library's source code is private. This repo is where anyone can report bugs, request features and see what's already known.

## Before you file

1. **Search first.** Check [open and closed issues](https://github.com/vjdesigns/vjdesigns-ui-issues/issues?q=is%3Aissue) for your problem.
2. **Make a reproduction.** Every docs example has an "Open in StackBlitz" button. Reproduce the bug there and include the link. Issues without a reproduction may be closed.
3. **Use the templates.** [Open a new issue](https://github.com/vjdesigns/vjdesigns-ui-issues/issues/new/choose) and pick Bug report or Feature request.

## Security

Never post security vulnerabilities publicly. See [SECURITY.md](SECURITY.md).

## Response times

- **Free users:** issues are triaged on a best-effort basis. There is no guaranteed response time.
- **vjdesigns-ui Pro customers:** use your private Pro support channel for priority support.

## Labels

| Label | Meaning |
| --- | --- |
| `needs triage` | New, not yet reviewed |
| `bug` | Confirmed or reported defect |
| `enhancement` | Feature request |
| `needs reproduction` | Waiting on a StackBlitz link |
| `duplicate` | Already reported elsewhere |
